## 1. 와이어프레임 변경사항

### 1.1 화면 ID 및 변경된 부분

이번 정리로 **자전거 예약 MVP 슬라이스 = 8개 화면**으로 확정됐다. 아래 3개 화면에
구조/추적 변경이, 상태 태그 관련 화면 3개에 상태 흐름 변경이 있었다.

#### 구조·추적 변경

| 화면코드 | 화면명 | 앵커 | 변경 유형 | 변경 내용 |
|---|---|---|---|---|
| **S3-C1** | 상품 상세 | `#detail` | 범위 확정 | 자전거 예약 MVP에 포함 확정. 화면코드는 규약(앞자리=기능군, S3=상품)상 **S3-C1 유지**. 예약 동선의 중간 화면이다: **상품조회(S1-C1) → 상품상세(S3-C1) → 예약·캘린더(S1-C2)**. 코드가 S3라서 다른 슬라이스로 오해하지 말 것 — 스프린트1 대상이다. |
| **S1-C6** | 예약 상세·바우처 | `#resdetail` | 추적 추가 | 노션 페이지 정의서에 누락돼 있던 것을 추가. 와이어프레임에는 원래 존재(`#resdetail`)했으므로 화면 자체는 그대로. 스프린트1 대상 화면으로 명확히 잡힘. |
| **S1-C1** | 상품조회 | `#list` | 메타 수정 | 슬라이스 값이 비어 있던 것을 자전거 예약 MVP로 채움. **화면 내용 변경 없음.** |

> 화면코드 앞자리는 **슬라이스가 아니라 기능군**이다(S0 계정 / S1 예약·운영 / S3 상품 / S4 콘텐츠).
> 어느 스프린트에 속하는지는 노션 페이지 정의서의 `슬라이스` 필드로 판단한다.

#### 상태 흐름 변경 (아래 1.2 — UI 영향 큼)

| 화면코드 | 화면명 | 앵커 | 변경 내용 |
|---|---|---|---|
| **S1-C4** | 입금 안내·확인 요청 | `#deposit` | 예약 생성 직후 상태 = **입금대기**(신규). '입금 확인 요청' 클릭 시 **입금대기 → 접수**로 전이. |
| **S1-C5** | 내 예약 목록 | `#myres` | 상태 태그에 **입금대기** 추가. 탭 구성(전체/접수/완료/취소)은 유지하되 **입금대기는 전용 탭 없이 '전체'에만 노출**. |
| **S1-C6** | 예약 상세·바우처 | `#resdetail` | 상태 태그 표기에 **입금대기** 추가. |

### 1.2 예약 상태 흐름 변경 (중요)

상태 흐름이 바뀌어 상태 태그/뱃지와 목록 탭 UI에 반영이 필요하다.

- 이전: `접수 → 완료 → 취소요청 → 취소`
- **변경: `입금대기 → 접수 → 완료` ; `취소요청 → 취소`**

전이 트리거:

| 시점 | 상태 |
|---|---|
| 예약 생성(입금 안내 진입) | **입금대기** |
| 고객 '입금 확인 요청' 클릭 | **접수** |
| 관리자 입금확인 (관리자 화면·스프린트1 범위 밖) | 완료 |
| 고객 취소 요청 (입금대기·접수에서 진입) | 취소요청 |
| 관리자 취소 처리 (관리자 화면) | 취소 |

UI에 반영할 것:

1. **상태 태그/뱃지에 '입금대기' 상태 추가** — 라벨 '입금대기', 색/스타일 정의 필요.
2. **S1-C5 목록 탭 매핑**
   - 접수 탭 = `RECEIVED`
   - 완료 탭 = `COMPLETED`
   - 취소 탭 = `CANCEL_REQUESTED` + `CANCELLED`
   - 입금대기(`AWAITING_DEPOSIT`)는 전용 탭 없음 → **전체 탭에서만** 보임
3. **상태 enum 코드값**(API 응답 `status`에 그대로 사용) — 태그 매핑 시 이 값을 키로 사용:

   | 상태(라벨) | enum 코드 |
   |---|---|
   | 입금대기 | `AWAITING_DEPOSIT` |
   | 접수 | `RECEIVED` |
   | 완료 | `COMPLETED` |
   | 취소요청 | `CANCEL_REQUESTED` |
   | 취소 | `CANCELLED` |

## 참고 — 아직 미확정(협의 중)이라 값이 바뀔 수 있는 부분

아래는 개발자·사장님 협의 중이라 UI에서 **잠정 처리**하고, 확정 시 갱신한다.

- **임시 홀드 타이머(S1-C2 담기 → S1-C3):** 홀드 유효시간(TTL) 미확정. 타이머 표기 자리는 잡아두되 시간값은 잠정.
- **취소 수수료(S1-C7):** 이용일 기준 차등 요율표 미확정. 수수료·환불액 표시 영역은 잡아두되 값은 잠정(현재 목은 0%).
- **2일+타지역 반납(S1-C2):** '익일·익익일 자동 마감'의 캘린더 표기 방식 미확정.

화면 목록·앵커·URL 경로의 최신 상태는 노션 페이지 정의서(슬라이스=자전거 예약 MVP)를 기준으로 본다.
