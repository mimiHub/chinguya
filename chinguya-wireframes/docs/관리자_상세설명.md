# 친구야 — 관리자 페이지 와이어프레임 상세 설명

- **대상 파일**: `../관리자_와이어프레임_모바일.html`
- **플랫폼**: 모바일 (저채도 · v1)
- **성격**: 접객 중 현장에서 쓰는 운영 화면. **일반 관리자는 조회 전용**, 쓰기는 **슈퍼어드민**. 22개 관리자 기능을 17개 대표 화면으로 정리.
- **문서 목적**: 각 화면의 `id`(HTML 앵커)와 화면 코드(예: S1-A3)별 기능·규칙·화면 이동을 정의해, 다른 협업자(및 그 Claude)가 와이어프레임을 정확히 이해·수정할 수 있도록 한다.

> **주석 범례**: 🟧 규칙·로직, 🟦 확정 대기·연동, 토글=ON/OFF, 빗금=이미지, 회색 라인=텍스트 자리.

## `a-login` · S0-A2 — 관리자 로그인

- **목적**: 관리자 **아이디/비밀번호 로그인**.
- **진입**: 관리자 앱 실행 시 첫 화면.
- **주요 요소**: 아이디·비밀번호 입력, 로그인 CTA.
- **규칙·로직**: 최초 구동 시 **슈퍼어드민 생성(S0-A1)** 1회 후 잠금, 이후 이 로그인 사용.
- **화면 이동**: 로그인 성공 → 대시보드(`a-dash`).

## `a-dash` · S1-A1 — 대시보드

- **목적**: 운영 현황과 **오늘 방문 예약**을 한눈에 파악.
- **진입**: 로그인 직후, 하단 탭 '홈'.
- **주요 요소**: 지표 카드(신규 예약/입금확인 요청/취소요청), 오늘 방문 예약 목록, 하단 탭.
- **규칙·로직**: '오늘 방문 예약' = 오늘 날짜 이용 건(일본 기준 '오늘').
- **화면 이동**: 예약 카드 → 예약 상세, 지표 → 해당 목록.

## `a-asset` · S1-A2 — 자산 관리

- **목적**: 보유 자산(자전거·낚싯대)의 **총 보유 대수** 관리.
- **진입**: 메뉴 → 자산 관리.
- **주요 요소**: 자산 카드(명칭·수량), + 등록 버튼.
- **규칙·로직**: 사유(수리/입고/외부임대)는 관리 안 함 **수량만** 관리, 삭제 = **소프트삭제**.
- **화면 이동**: + 등록 → 자산 등록 폼, 카드 → 상세/수정.

## `a-inv` · S1-A3 — 날짜별 재고 세팅

- **목적**: 날짜별 **고객 가용 수량·휴무**를 달력 뷰로 세팅.
- **진입**: 메뉴 → 재고 세팅.
- **주요 요소**: 상품 선택, 달력(여유/임박/마감/휴무 색상), 선택일 상세(총 보유·여행사 할당·고객 가용·휴무 토글).
- **규칙·로직**:
  - 셀 숫자 = 그 날짜의 **고객 가용 수량**. 색상으로 여유/임박/마감/휴무를 구분.
  - **Slice 1**은 관리자가 **고객 가용 수량 직접 세팅**.
  - **Slice 2**부터 **총 보유 − 여행사 할당 = 고객 가용**으로 자동 계산.
- **화면 이동**: 날짜 탭 → 하단 상세 편집, 저장 → 반영.

## `a-prod` · S1-A4 — 상품 관리 목록

- **목적**: 상품 목록 조회 및 **표출 ON/OFF** 관리.
- **진입**: 메뉴 → 상품 관리, 하단 탭 '상품'.
- **주요 요소**: 상품 카드(명칭·옵션·표출 토글), + 등록 버튼.
- **규칙·로직**: 상품별 **고객앱 / 여행사앱 표출**을 각각 토글.
- **화면 이동**: + 등록/카드 → 상품 등록·수정(`a-prodedit`).

## `a-prodedit` · S1-A5 — 상품 등록/수정

- **목적**: 상품의 **가격·표출·설명·이미지** 등록/수정.
- **진입**: 상품 관리 목록의 + 등록/카드.
- **주요 요소**: 고객가·여행사가, 고객앱·여행사앱 표출 토글, 타지역 반납 추가요금, 상세 설명, 이미지.
- **규칙·로직**: 여행사가 컬럼은 항상 보유(**고객앱 미노출**), 타지역 반납 추가요금은 **전기 2일 상품에만**.
- **화면 이동**: 저장 → 상품 관리 목록.

## `a-res` · S1-A6 — 예약 관리 목록

- **목적**: 전체 예약을 **상태별**로 조회·검색.
- **진입**: 메뉴 → 예약 관리, 대시보드 지표.
- **주요 요소**: 상태 탭, 검색(예약번호·여권명), 예약 카드(상태 태그).
- **규칙·로직**: 필터 **접수/완료/미입금/취소요청/취소**, 목록·검색·페이지네이션.
- **화면 이동**: 예약 카드 → 예약 상세·입금확인(`a-resdetail`).

## `a-resdetail` · S1-A7/A8 — 예약 상세 · 입금확인

- **목적**: 예약 상세 확인 및 **입금 확인 → 완료 처리**.
- **진입**: 예약 관리 목록의 예약 카드.
- **주요 요소**: 예약번호·고객·여권명·상품·이용일·입금액, 완료 처리 CTA, 미입금 강제 취소.
- **규칙·로직**: 입금 확인 시 상태 **완료**, 접수 후 **24시간 내 미입금** 시 '미입금' 표시 → 강제 취소(재고 즉시 복원).
- **화면 이동**: 완료 처리/강제 취소 → 예약 관리 목록 상태 반영.

## `a-cancel` · S1-A9 — 취소요청 처리

- **목적**: 고객 **취소요청** 검토 후 환불·취소 확정.
- **진입**: 예약 관리(취소요청 탭)의 예약 카드.
- **주요 요소**: 결제액·취소 수수료(차등)·환불 예정액·고객 환불계좌, 취소 확정 CTA.
- **규칙·로직**: 수수료는 **이용일 기준 차등**, 환불 이체는 **수동**, 이체 후 '취소' 처리 → 재고 즉시 복원.
- **화면 이동**: 취소 확정 → 예약 상태 취소.

## `a-set` · S1-A10 — 계좌 · 정책 설정

- **목적**: **입금 계좌**와 **차등 취소 수수료 정책** 설정.
- **진입**: 메뉴 → 계좌·정책.
- **주요 요소**: 입금 계좌(한국 1건), 이용일 기준 구간별 수수료율(예: D-7 이전 0%, D-3~D-6 20%, D-1~D-2 50%), 저장.
- **규칙·로직**: 구간·요율 **수치는 관리자 편집**, 여행사 취소 마감 기준일도 여기서 **유연 조정**(기본 D-3).
- **화면 이동**: 저장 → 정책 반영(취소 계산에 적용).

## `a-admins` · S0-A5/A6 — 관리자 관리

- **목적**: 관리자 계정 **등급 관리**(슈퍼어드민/일반).
- **진입**: 메뉴 → 관리자 관리(슈퍼어드민 전용).
- **주요 요소**: 관리자 카드(아이디·등급 태그), + 추가 버튼.
- **규칙·로직**: 일반 관리자는 **조회 전용**(접객용), 추가/수정/처리·설정은 **슈퍼어드민만**.
- **화면 이동**: + 추가/카드 → 관리자 등록·수정.

## `a-agency` · S2-A1/A3 — 여행사 관리

- **목적**: 여행사 계정 목록 관리 및 **사용 가능/불가** 토글.
- **진입**: 메뉴 → 여행사 관리.
- **주요 요소**: 여행사 카드(명칭·사용 토글), + 등록 버튼.
- **규칙·로직**: 토글 = 사용 가능/불가, 담당자 변경은 상세에서, **불가 시 로그인·예약 차단**.
- **화면 이동**: + 등록 → 여행사 등록(`a-agencyadd`), 카드 → 상세.

## `a-agencyadd` · S2-A2 — 여행사 등록(초대)

- **목적**: 여행사 **초대 이메일 발송**으로 계정 등록 유도.
- **진입**: 여행사 관리의 + 등록.
- **주요 요소**: 여행사명·담당자 이메일 입력, 가입 링크 발송 CTA.
- **규칙·로직**: 담당자가 링크로 **아이디·비밀번호 직접 등록**, 링크 **유효기간 1주일**, 이미 계정 있으면 발송 생략.
- **화면 이동**: 발송 → 여행사 관리 목록.
- **연동**: 여행사 측 계정 등록 화면은 여행사 파일 `g-invite`(S2-G1/G2).

## `a-alloc` · S2-A4 — 날짜별 할당 세팅

- **목적**: 여행사별·날짜별 **재고 할당 수량** 세팅.
- **진입**: 메뉴 → 할당 세팅.
- **주요 요소**: 여행사·상품·날짜 선택, 수량 스테퍼, 저장.
- **규칙·로직**: 할당 단위 = **자전거 종류·날짜별 수량**, **총 보유 − 할당 = 고객 가용**(자동), 여행사 예약기간 **+3일 ~ +3개월**.
- **화면 이동**: 저장 → 재고 세팅·여행사 예약에 반영.

## `a-invoice` · S2-A5/A6 — 인보이스 관리

- **목적**: 여행사 **월별 인보이스** 발행·관리.
- **진입**: 메뉴 → 인보이스.
- **주요 요소**: 여행사·월별 인보이스 카드(발행 상태 태그).
- **규칙·로직**: 통화 **KRW**(세금 라인 없음), **매월 1일 전월 기준** 발행, 라인아이템 = 예약 건, 정산은 **수동 확인**.
- **화면 이동**: 카드 → 인보이스 상세.

## `a-qna` · S4-A2 — 문의 관리

- **목적**: 고객 1:1 문의 확인 및 **답변 등록**.
- **진입**: 메뉴 → 문의 관리, 대시보드/알림.
- **주요 요소**: 문의 본문, 답변 입력, 답변 등록 CTA.
- **규칙·로직**: 답변 등록 시 고객에게 **카카오 알림톡** 발송(알림 인터페이스, 실발송 이연).
- **화면 이동**: 답변 등록 → 문의 목록(답변완료).

## `a-cms` · S4-A1/A3 — FAQ · 콘텐츠 관리 (CMS-lite)

- **목적**: **FAQ·랜딩·서비스 소개** 콘텐츠 편집.
- **진입**: 메뉴 → FAQ·콘텐츠.
- **주요 요소**: FAQ 항목(순서 드래그), + FAQ 버튼, 랜딩·소개 콘텐츠 편집 영역.
- **규칙·로직**: FAQ 등록/수정/삭제·**노출 순서** 관리, **분류·검색 없음**, 랜딩/소개 텍스트·이미지 편집.
- **화면 이동**: 편집 → 고객 FAQ·랜딩·서비스 소개(`s4-c2` 등)에 반영.
