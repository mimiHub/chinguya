## `landing` · 안 A — 랜딩(상품 우선형) **[확정]**

- **목적**: 고객이 **서비스 소개**를 먼저 접한 뒤 자연스럽게 예약으로 이어지도록 유도.
- **진입**: 앱 실행 시 홈 탭 기본 화면(안 A 확정).
- **주요 요소**: 히어로 이미지, 서비스 소개 CTA(최상단 고정), 인기 상품 썸네일, 카테고리 칩(자전거/낚싯대), 하단 탭 내비게이션(홈/상품/장바구니/내정보).
- **규칙·로직**: 관리자 **'표출 ON'** 상품만 노출, 가격은 **고객가** 기준.
- **화면 이동**: 서비스 소개 CTA → `s4-c2`(서비스 소개), 하단 탭 → 상품/장바구니/내정보.

## `s4-c2` · S4-C2 — 서비스 소개

- **목적**: 서비스 개요·이용 방식을 소개하는 **단일 상세 페이지**.
- **진입**: 랜딩(안 A)의 '서비스 소개' CTA, 하단/상단 메뉴.
- **주요 요소**: 히어로 이미지, 소개 본문, 중간 이미지 블록.
- **규칙·로직**: 모든 텍스트·이미지는 관리자 **콘텐츠 관리(S4-A3)**에서 편집하며 고객은 **읽기 전용**.
- **화면 이동**: 본문 내 링크/버튼 → 상품 조회(`list`).

## `list` · S1-C1 — 상품 조회

- **목적**: 대여 가능 상품(자전거·낚싯대)을 **카테고리별**로 조회.
- **진입**: 하단 탭 '상품', 랜딩 CTA.
- **주요 요소**: 카테고리 칩(자전거/낚싯대), 상품 카드(썸네일·명칭·요약가).
- **규칙·로직**: 관리자 **'표출 ON'** 상품만 노출, 가격은 **고객가** 기준.
- **화면 이동**: 상품 카드 → 상품 상세(`detail`).

## `detail` · S3-C1 — 상품 상세

- **목적**: 선택 상품의 **대여 옵션·요금**을 확인하고 **옵션(대여시간)을 선택**해 예약 시작.
- **진입**: 상품 조회 목록의 상품 카드.
- **주요 요소**: **이전 페이지로 이동 버튼**, 대표 이미지, 상품 설명, 옵션 칩(2시간/1일/2일/야간, **선택형**), 요금, 예약하기 CTA.
- **규칙·로직**:
  - 옵션(대여시간)별 요금 표기. **2일 대여** 선택 시 **타지역 반납(추가요금)** 옵션 노출.
  - **여기서 선택한 옵션**이 예약 캘린더(`booking`)의 날짜 선택 규칙을 결정: 2시간·1일 → **1일 선택**, 2일 → **2일 선택**, 야간 → **야간 가능일 중 1일 선택**. (옵션 선택은 상품 상세에서만 이뤄지며, 예약 캘린더에서는 변경 불가 — 중복 방지)
- **화면 이동**: **이전 페이지로 이동 → 상품 조회(`list`)**, 예약하기 → 예약·캘린더(`booking`, **선택한 옵션 전달**).

## `booking` · S1-C2 — 예약 · 캘린더

- **목적**: 전달받은 옵션에 맞춰 날짜·수량을 선택해 예약 항목 확정.
- **진입**: 상품 상세의 '예약하기'(**선택한 옵션 포함**).
- **주요 요소**: **이전 페이지로 이동 버튼**, 선택된 옵션 표시(**읽기전용**, 상품 상세에서 전달), 가용성 캘린더(가능/선택/마감), 수량 스테퍼, 장바구니 담기·바로 예약.
- **규칙·로직**:
  - **날짜 선택 개수는 옵션에 따름**: 2시간·1일 = **1일 선택**, 2일 = **연속 2일 선택**, 야간 = **야간 가능일 중 1일 선택**.
  - 예약 가능 기간 **오늘 +1일 ~ +3개월**(일본 기준 '오늘').
  - 가용성 = **재고 × 슬롯 겹침**으로 판정.
  - 선택 날짜·옵션의 **가용 수량 상한** 내에서만 수량 선택 가능.
  - **2일 + 타지역 반납** 선택 시 **익일·익익일 자동 마감**.
- **화면 이동**: **이전 페이지로 이동 → 상품 상세(`detail`)**, 장바구니 담기 → **토스트('장바구니에 추가되었습니다.')** 노출 후 현재 화면 유지 / 바로 예약 → 여권 영문명 입력·확인 화면(`cart`, S1-C3).
- **인터랙션 참고**: `data-toast` 속성 버튼 클릭 시 하단 토스트가 1.8초간 노출(파일 하단 `<script>`).

## `cart` · S1-C3 — 장바구니 · 예약 확인

- **목적**: 복수 상품을 **동시 예약**하고 여권명·합계 확인 후 확정.
- **진입**: 예약 캘린더의 '장바구니 담기', 하단 탭 예약.
- **주요 요소**: **이전 페이지로 이동 버튼**, 담긴 항목(수량 표시), 임시 홀드 타이머, 여권 영문명, 합계, 확정 CTA.
- **규칙·로직**:
  - **임시 홀드**로 중복 예약 방지(남은 시간 카운트다운 표시).
  - 저장된 여권 영문명 없으면 **필수 입력**(확정 선행조건), 있으면 수정 가능.
  - 수량 변경은 예약 화면(`booking`)의 수량 선택에서.
- **화면 이동**: **이전 페이지로 이동 → 예약·캘린더(`booking`)**, '예약하고 입금 안내 받기' → 입금 안내(`deposit`).

## `deposit` · S1-C4 — 입금 안내 · 확인 요청

- **목적**: 무통장 입금 안내 후 **수동 확인 요청** 접수.
- **진입**: 예약 확인의 '예약하고 입금 안내 받기'.
- **주요 요소**: **이전 페이지로 이동 버튼**, 예약번호, 입금 계좌·예금주·입금액, 입금 확인 요청 CTA.
- **규칙·로직**:
  - **PG 미사용**. 안내 계좌(관리자 설정 1개)로 입금.
  - 확인 요청 시 상태 **접수**.
  - **24시간 내 미입금** 시 관리자 강제취소 가능.
- **화면 이동**: **이전 페이지로 이동 → 장바구니(`cart`)**, 입금 확인 요청 → 예약 목록(상태: 접수)(`myres`).

## `myres` · S1-C5 — 예약 목록

- **목적**: 내 예약을 **상태별**로 조회.
- **진입**: 하단 탭 '내정보' → 내 예약, 입금 확인 요청 후.
- **주요 요소**: 상태 탭(전체/접수/완료/취소), 예약 카드(상태 태그).
- **규칙·로직**: 상태 흐름 **접수 → 완료(입금확인) → 취소요청 → 취소**.
- **화면 이동**: 예약 카드 → 예약 상세·바우처(`resdetail`).

## `resdetail` · S1-C6 — 예약 상세 · 바우처

- **목적**: 예약 증빙(**바우처**) 확인 및 취소 요청 진입.
- **진입**: 예약 목록의 예약 카드.
- **주요 요소**: 상태 태그, 예약번호, 상품·옵션, 이용일, 여권명, 취소 요청 버튼.
- **규칙·로직**: 예약번호가 현장 이용 시 **증빙** 역할. 취소는 상태·기간 조건 충족 시 가능.
- **화면 이동**: 취소 요청 → 취소 요청 화면(`cancel`).

## `cancel` · S1-C7 — 취소 요청

- **목적**: 취소 수수료·환불액 확인 후 **취소 요청** 제출.
- **진입**: 예약 상세의 '취소 요청'.
- **주요 요소**: 결제 금액·취소 수수료·환불 예정액, 환불 계좌 입력, 취소 요청 보내기.
- **규칙·로직**:
  - 수수료는 **이용일 기준 차등 요율**(관리자 세팅).
  - 고객은 수수료·환불액을 **확인 후** 진행.
  - 환불 계좌는 **취소 요청 시점**에 입력, 실제 이체는 관리자 **수동 처리**.
- **화면 이동**: 취소 요청 보내기 → 예약 목록(상태: 취소요청).

## `faq` · S4-C3 — FAQ

- **목적**: 자주 묻는 질문을 **아코디언**으로 열람.
- **진입**: 내정보/고객지원 메뉴.
- **주요 요소**: 질문 항목(＋ 펼침), 펼친 답변 본문.
- **규칙·로직**: **검색 없음**, 분류(카테고리)는 차후 확정, 콘텐츠는 관리자 FAQ 관리에서 편집.
- **화면 이동**: 해결 안 될 시 → 질문하기(`qna`).

## `qna` · S4-C4 — 질문하기(목록)

- **목적**: 고객 1:1 문의를 목록으로 조회하고 신규 작성.
- **진입**: 내정보/고객지원 메뉴, FAQ에서 이동.
- **주요 요소**: 질문 카드(제목·상태 태그), 타인 글 잠금 표시, 질문 작성 CTA.
- **규칙·로직**: **목록은 전체 공개**(제목·상태), **상세 내용·답변은 작성 본인만** 열람, 타인 글은 잠금 표시.
- **화면 이동**: 본인 카드 → 질문 상세(S4-C5), 질문 작성 → 작성 폼.

## S4-C5 — 질문하기(상세/작성)

> HTML상 `qna` 그룹 내 세 번째 `.screen` 블록(별도 `id` 없음).

- **목적**: 본인 질문·답변 열람 및 신규 질문 등록.
- **진입**: 질문 목록의 본인 카드/질문 작성.
- **주요 요소**: 내 질문 본문(삭제 버튼), 관리자 답변, 새 질문 입력·등록.
- **규칙·로직**: 질문 **삭제 가능·수정 불가**. 답변 등록 시 **카카오 알림톡** 알림(알림 인터페이스).
- **화면 이동**: 등록 → 질문 목록에 반영.

## `signup` · S0-C1 — 회원가입(소셜 로그인)

- **목적**: 소셜 로그인 기반 **회원가입** 시작.
- **진입**: 예약 등 로그인 필요 액션, 내정보.
- **주요 요소**: 소셜 버튼(카카오/네이버/구글).
- **규칙·로직**: 소셜 제공자 **추후 확장 가능** 구조.
- **화면 이동**: 소셜 인증 완료 → S0-C2(아이디 입력).

## S0-C2 — 회원가입(아이디 입력)

> HTML상 `signup` 그룹 내 두 번째 `.screen` 블록(별도 `id` 없음).

- **목적**: 소셜 인증 후 **아이디** 설정으로 가입 완료.
- **진입**: S0-C1 소셜 인증 완료 후.
- **주요 요소**: 아이디 입력, 가입 완료 CTA.
- **규칙·로직**: 여권 영문명은 **예약 시점**에 확보(가입 단계 아님).
- **화면 이동**: 가입 완료 → 직전 화면/홈.

## `profile` · S0-C3 — 회원정보 수정

- **목적**: 계정 정보 확인 및 **여권 영문명** 관리.
- **진입**: 하단 탭 '내정보' → 내 정보.
- **주요 요소**: 아이디·연결 소셜(읽기), 여권 영문명(변경 가능), 저장, 로그아웃, 회원 탈퇴.
- **규칙·로직**: 여권 영문명은 언제든 변경 가능(예약 시 사용). **회원 탈퇴 시 개인정보 삭제**.
- **화면 이동**: 로그아웃/탈퇴 → 로그아웃 상태 홈.
