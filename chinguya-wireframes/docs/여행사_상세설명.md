- **대상 파일**: `../여행사_와이어프레임_데스크톱.html`

- **문서 목적**: 각 화면의 `id`(HTML 앵커)와 화면 코드(예: S2-G4/G5)별 기능·규칙·화면 이동을 정의해, 다른 협업자(및 그 Claude)가 와이어프레임을 정확히 이해·수정할 수 있도록 한다.

## `g-invite` · S2-G1/G2 — 계정 등록(초대 링크) · 로그인

- **목적**: 여행사 담당자의 **계정 등록(초대 링크)** 및 로그인.
- **진입**: 관리자 초대 이메일의 링크(토큰 포함, `.../agency/invite?token=…`).
- **주요 요소**: 아이디·비밀번호·비밀번호 확인 입력, 계정 등록 완료, 등록 후 로그인 폼.
- **규칙·로직**: 관리자 초대 이메일 링크로 진입, **링크 유효기간 1주일**, 담당자가 아이디·비번 **직접 설정**.
- **화면 이동**: 등록/로그인 성공 → 여행사 대시보드(`g-dash`).
- **연동**: 관리자 측 초대 발송 화면은 관리자 파일 `a-agencyadd`(S2-A2).

## `g-dash` · S2-G3 — 여행사 대시보드

- **목적**: 신규 예약 현황과 **오늘 이용자 명단** 확인.
- **진입**: 로그인 직후, 좌측 사이드바 '대시보드'.
- **주요 요소**: 신규 예약 지표 카드, 오늘 이용자 명단 표(예약번호·상품·수량·여권명·상태).
- **규칙·로직**: 여행사 예약은 상태 단순 — **예약 = 즉시 완료 / 취소 = 즉시**, 입금 흐름 없음.
- **화면 이동**: 사이드바 → 상품 예약(`g-book`)·예약 목록(`g-list`)·인보이스(`g-invoice`).

## `g-book` · S2-G4/G5 — 상품 조회 · 예약

- **목적**: 할당 범위 내에서 상품 조회 후 **즉시 예약**.
- **진입**: 사이드바 '상품 예약'.
- **주요 요소**: 이용 날짜, 상품 표(여행사가·가용·수량 스테퍼), 예약 요약·합계, 예약(즉시 완료) CTA.
- **규칙·로직**:
  - 가용 = **여행사 할당 수량** 상한(초과 선택 불가).
  - 예약 가능 기간 **오늘 +3일 ~ +3개월**.
  - 가격은 **여행사가** 적용.
- **화면 이동**: 예약 → 예약 목록/대시보드.

## `g-list` · S2-G6 — 여행사 예약 목록

- **목적**: 여행사 예약 내역 조회 및 **즉시 취소**.
- **진입**: 사이드바 '예약 목록'.
- **주요 요소**: 예약 표(예약번호·이용일·상품·수량·금액·상태), 취소 버튼.
- **규칙·로직**: 취소 = **즉시**(재고 즉시 복원), 기본 **이용일 3일 전(D-3)까지**만 가능, 기준일은 관리자가 **유연 조정**(D-2·D-1 등). 마감 경과 건은 '취소불가' 표시.
- **화면 이동**: 취소 → 상태 취소로 갱신.

## `g-invoice` · S2-G7 — 여행사 인보이스

- **목적**: 월별 **인보이스(정산 내역)** 확인.
- **진입**: 사이드바 '인보이스'.
- **주요 요소**: 월·통화 표시, 라인아이템 표(일자·예약번호·상품·수량·단가·금액), 합계.
- **규칙·로직**: **매월 1일 전월 기준** 발행, **KRW·세금 라인 없음**, 실제 정산(입금)은 시스템 밖 **수동 확인**.
- **화면 이동**: (조회 전용).
