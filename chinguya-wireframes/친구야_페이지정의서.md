## 1. 고객 페이지 (모바일)

### 안 A — 랜딩(상품 우선형)
- **목적**: 고객이 **서비스 소개**를 먼저 접한 뒤 자연스럽게 예약으로 이어지도록 유도
- **진입**: 앱 실행 시 홈 탭 기본 화면(안 A 확정)
- **주요 요소**: 히어로 이미지, 서비스 소개 CTA(최상단 고정), 인기 상품 썸네일, 카테고리 칩
- **규칙·로직**: 관리자 **'표출 ON'** 상품만 노출, 가격은 고객가 기준
- **화면 이동**: 서비스 소개 → 서비스 소개(S4-C2), 하단 탭 → 상품·예약·내정보

### S4-C2 — 서비스 소개
- **목적**: 서비스 개요·이용 방식을 소개하는 **단일 상세 페이지**
- **진입**: 랜딩(안 A)의 '서비스 소개' CTA, 하단/상단 메뉴
- **주요 요소**: 히어로 이미지, 소개 본문, 중간 이미지 블록
- **규칙·로직**: 모든 텍스트·이미지는 관리자 **콘텐츠 관리(S4-A3)**에서 편집(고객은 읽기 전용)
- **화면 이동**: 본문 내 링크/버튼 → 상품 조회

### S1-C1 — 상품 조회
- **목적**: 대여 가능 상품(자전거·낚싯대)을 **카테고리별**로 조회
- **진입**: 하단 탭 '상품', 랜딩 CTA
- **주요 요소**: 카테고리 칩(자전거/낚싯대), 상품 카드(썸네일·명칭·요약가)
- **규칙·로직**: 관리자 **'표출 ON'** 상품만 노출, 가격은 **고객가** 기준
- **화면 이동**: 상품 카드 → 상품 상세

### S3-C1 — 상품 상세
- **목적**: 선택 상품의 **대여 옵션·요금**을 확인하고 예약 시작
- **진입**: 상품 조회 목록의 상품 카드
- **주요 요소**: 대표 이미지, 상품 설명, 옵션 칩(2시간/1일/2일/야간), 요금, 예약하기 CTA
- **규칙·로직**: 옵션(대여시간)별 요금 표기, 2일 대여 선택 시 **타지역 반납(추가요금)** 옵션 노출
- **화면 이동**: 예약하기 → 예약·캘린더

### S1-C2 — 예약·캘린더
- **목적**: 옵션·날짜·수량을 선택해 예약 항목 확정
- **진입**: 상품 상세의 '예약하기'
- **주요 요소**: 옵션 칩, 가용성 캘린더(가능/선택/마감), 수량 스테퍼, 장바구니 담기·바로 예약
- **규칙·로직**: 예약 가능 기간 **오늘 +1일 ~ +3개월**(일본 기준), 가용성 = 재고×슬롯 겹침, 가용 수량 상한 내 선택, 2일+타지역 반납 시 **익일·익익일 자동 마감**
- **화면 이동**: 장바구니 담기 → **토스트('장바구니에 추가되었습니다.')** 노출 후 현재 화면 유지, 바로 예약 → 장바구니(S1-C3)

### S1-C3 — 장바구니
- **목적**: 복수 상품을 **동시 예약**하고 여권명·합계 확인 후 확정
- **진입**: 예약 캘린더의 '장바구니 담기', 하단 탭 예약
- **주요 요소**: 담긴 항목(수량 표시), 임시 홀드 타이머, 여권 영문명, 합계, 확정 CTA
- **규칙·로직**: **임시 홀드**로 중복 예약 방지, 저장된 여권 영문명 없으면 **필수 입력**(확정 선행조건), 수량 변경은 예약 화면에서
- **화면 이동**: 예약하고 입금 안내 받기 → 입금 안내

### S1-C4 — 입금 안내·확인 요청
- **목적**: 무통장 입금 안내 후 **수동 확인 요청** 접수
- **진입**: 장바구니의 '예약하고 입금 안내 받기'
- **주요 요소**: 예약번호, 입금 계좌·예금주·입금액, 입금 확인 요청 CTA
- **규칙·로직**: **PG 미사용**, 안내 계좌(관리자 설정 1개), 확인 요청 시 상태 **접수**, **24시간 내 미입금** 시 관리자 강제취소 가능
- **화면 이동**: 입금 확인 요청 → 예약 목록(상태: 접수)

### S1-C5 — 예약 목록
- **목적**: 내 예약을 **상태별**로 조회
- **진입**: 하단 탭 '내정보' → 내 예약, 입금 확인 요청 후
- **주요 요소**: 상태 탭(전체/접수/완료/취소), 예약 카드(상태 태그)
- **규칙·로직**: 상태 흐름: **접수 → 완료(입금확인) → 취소요청 → 취소**
- **화면 이동**: 예약 카드 → 예약 상세·바우처

### S1-C6 — 예약 상세·바우처
- **목적**: 예약 증빙(**바우처**) 확인 및 취소 요청 진입
- **진입**: 예약 목록의 예약 카드
- **주요 요소**: 상태 태그, 예약번호, 상품·옵션, 이용일, 여권명, 취소 요청 버튼
- **규칙·로직**: 예약번호가 현장 이용 시 **증빙** 역할, 취소는 상태·기간 조건 충족 시 가능
- **화면 이동**: 취소 요청 → 취소 요청 화면

### S1-C7 — 취소 요청
- **목적**: 취소 수수료·환불액 확인 후 **취소 요청** 제출
- **진입**: 예약 상세의 '취소 요청'
- **주요 요소**: 결제 금액·취소 수수료·환불 예정액, 환불 계좌 입력, 취소 요청 보내기
- **규칙·로직**: 수수료는 **이용일 기준 차등 요율**(관리자 세팅), 고객은 확인 후 진행, 환불 계좌는 **요청 시점 입력**, 실제 이체는 관리자 **수동 처리**
- **화면 이동**: 취소 요청 보내기 → 예약 목록(상태: 취소요청)

### S4-C3 — FAQ
- **목적**: 자주 묻는 질문을 **아코디언**으로 열람
- **진입**: 내정보/고객지원 메뉴
- **주요 요소**: 질문 항목(＋ 펼침), 펼친 답변 본문
- **규칙·로직**: **검색 없음**, 분류(카테고리)는 차후 확정, 콘텐츠는 관리자 FAQ 관리에서 편집
- **화면 이동**: 해결 안 될 시 → 질문하기

### S4-C4 — 질문하기 — 목록
- **목적**: 고객 1:1 문의를 목록으로 조회하고 신규 작성
- **진입**: 내정보/고객지원 메뉴, FAQ에서 이동
- **주요 요소**: 질문 카드(제목·상태 태그), 타인 글 잠금 표시, 질문 작성 CTA
- **규칙·로직**: **목록은 전체 공개**(제목·상태), **상세 내용·답변은 작성 본인만** 열람, 타인 글은 잠금
- **화면 이동**: 본인 카드 → 질문 상세, 질문 작성 → 작성 폼

### S4-C5 — 질문하기 — 상세/작성
- **목적**: 본인 질문·답변 열람 및 신규 질문 등록
- **진입**: 질문 목록의 본인 카드/질문 작성
- **주요 요소**: 내 질문 본문(삭제 버튼), 관리자 답변, 새 질문 입력·등록
- **규칙·로직**: 질문 **삭제 가능·수정 불가**, 답변 등록 시 **카카오 알림톡** 알림
- **화면 이동**: 등록 → 질문 목록에 반영

### S0-C1 — 회원가입 — 소셜
- **목적**: 소셜 로그인 기반 **회원가입** 시작
- **진입**: 예약 등 로그인 필요 액션, 내정보
- **주요 요소**: 소셜 버튼(카카오/네이버/구글)
- **규칙·로직**: 소셜 제공자 **추후 확장 가능** 구조
- **화면 이동**: 소셜 인증 완료 → S0-C2(아이디 입력)

### S0-C2 — 회원가입 — 아이디
- **목적**: 소셜 인증 후 **아이디** 설정으로 가입 완료
- **진입**: S0-C1 소셜 인증 완료 후
- **주요 요소**: 아이디 입력, 가입 완료 CTA
- **규칙·로직**: 여권 영문명은 **예약 시점**에 확보(가입 단계 아님)
- **화면 이동**: 가입 완료 → 직전 화면/홈

### S0-C3 — 회원정보 수정
- **목적**: 계정 정보 확인 및 **여권 영문명** 관리
- **진입**: 하단 탭 '내정보' → 내 정보
- **주요 요소**: 아이디·연결 소셜(읽기), 여권 영문명(변경 가능), 저장, 로그아웃, 회원 탈퇴
- **규칙·로직**: 여권 영문명은 언제든 변경 가능(예약 시 사용), **회원 탈퇴 시 개인정보 삭제**
- **화면 이동**: 로그아웃/탈퇴 → 로그아웃 상태 홈

## 2. 관리자 페이지 (모바일)

> 접객 중 현장에서 쓰는 화면. 일반 관리자는 **조회 전용**, 쓰기·설정·처리는 **슈퍼어드민**만.

### S0-A2 — 관리자 로그인
- **목적**: 관리자 **아이디/비밀번호 로그인**
- **진입**: 관리자 앱 실행 시 첫 화면
- **주요 요소**: 아이디·비밀번호 입력, 로그인 CTA
- **규칙·로직**: 최초 구동 시 **슈퍼어드민 생성(S0-A1)** 1회 후 잠금, 이후 이 로그인 사용
- **화면 이동**: 로그인 성공 → 대시보드

### S0-A5 — 관리자 목록
- **목적**: 관리자 계정 **목록·등급 조회**(슈퍼어드민/일반)
- **진입**: 메뉴 → 관리자 관리(슈퍼어드민 전용)
- **주요 요소**: 관리자 카드(아이디·등급 태그), + 추가 버튼
- **규칙·로직**: 일반 관리자는 **조회 전용**(접객용), 추가/수정은 **슈퍼어드민만**
- **화면 이동**: + 추가/카드 → 관리자 등록/수정(S0-A6)

### S0-A6 — 관리자 등록/수정
- **목적**: 관리자 계정 **등록·수정 및 등급 지정**
- **진입**: 관리자 목록의 + 추가/카드
- **주요 요소**: 아이디·비밀번호, 등급 선택(슈퍼어드민/일반), 저장
- **규칙·로직**: 일반 = **조회 전용**, 등록/수정은 **슈퍼어드민만**, 삭제 = **소프트삭제**
- **화면 이동**: 저장 → 관리자 목록

### S1-A1 — 대시보드
- **목적**: 운영 현황과 **오늘 방문 예약**을 한눈에 파악
- **진입**: 로그인 직후, 하단 탭 '홈'
- **주요 요소**: 지표 카드(신규 예약/입금확인 요청/취소요청), 오늘 방문 예약 목록, 하단 탭
- **규칙·로직**: '오늘 방문 예약' = 오늘 날짜 이용 건(일본 기준 '오늘')
- **화면 이동**: 예약 카드 → 예약 상세, 지표 → 해당 목록

### S1-A2 — 자산 관리
- **목적**: 보유 자산(자전거·낚싯대)의 **총 보유 대수** 관리
- **진입**: 메뉴 → 자산 관리
- **주요 요소**: 자산 카드(명칭·수량), + 등록 버튼
- **규칙·로직**: 사유(수리/입고/외부임대)는 관리 안 함 **수량만** 관리, 삭제 = **소프트삭제**
- **화면 이동**: + 등록 → 자산 등록 폼, 카드 → 상세/수정

### S1-A3 — 날짜별 재고 세팅
- **목적**: 날짜별 **고객 가용 수량·휴무**를 달력 뷰로 세팅
- **진입**: 메뉴 → 재고 세팅
- **주요 요소**: 상품 선택, 달력(여유/임박/마감/휴무 색상), 선택일 상세(총 보유·여행사 할당·고객 가용·휴무 토글)
- **규칙·로직**: 셀 숫자 = 그 날짜 **고객 가용 수량**. Slice 1은 **직접 세팅**, Slice 2부터 **총 보유 − 여행사 할당 = 고객 가용** 자동
- **화면 이동**: 날짜 탭 → 하단 상세 편집, 저장 → 반영

### S1-A4 — 상품 관리 목록
- **목적**: 상품 목록 조회 및 **표출 ON/OFF** 관리
- **진입**: 메뉴 → 상품 관리, 하단 탭 '상품'
- **주요 요소**: 상품 카드(명칭·옵션·표출 토글), + 등록 버튼
- **규칙·로직**: 상품별 **고객앱 / 여행사앱 표출**을 각각 토글
- **화면 이동**: + 등록/카드 → 상품 등록·수정

### S1-A5 — 상품 등록/수정
- **목적**: 상품의 **가격·표출·설명·이미지** 등록/수정
- **진입**: 상품 관리 목록의 + 등록/카드
- **주요 요소**: 고객가·여행사가, 고객앱·여행사앱 표출 토글, 타지역 반납 추가요금, 상세 설명, 이미지
- **규칙·로직**: 여행사가 컬럼은 항상 보유(**고객앱 미노출**), 타지역 반납 추가요금은 **전기 2일 상품에만**
- **화면 이동**: 저장 → 상품 관리 목록

### S1-A6 — 예약 관리 목록
- **목적**: 전체 예약을 **상태별**로 조회·검색
- **진입**: 메뉴 → 예약 관리, 대시보드 지표
- **주요 요소**: 상태 탭, 검색(예약번호·여권명), 예약 카드(상태 태그)
- **규칙·로직**: 필터: **접수/완료/미입금/취소요청/취소**, 목록·검색·페이지네이션
- **화면 이동**: 예약 카드 → 예약 상세(S1-A7)

### S1-A7 — 예약 상세
- **목적**: 예약 **상세 정보 조회**
- **진입**: 예약 관리 목록의 예약 카드
- **주요 요소**: 예약번호·고객·여권명·상품·이용일·입금액·상태 태그
- **규칙·로직**: 조회 전용 화면, 상태 변경 처리는 **입금확인(S1-A8)**에서 수행
- **화면 이동**: 입금확인 처리로 이동 → S1-A8

### S1-A8 — 입금확인
- **목적**: **입금 확인 → 완료 처리** 및 미입금 강제 취소
- **진입**: 예약 상세(S1-A7)의 처리 이동, 대시보드 '입금확인 요청'
- **주요 요소**: 예약번호·입금 예정액·입금자명 확인, 완료 처리 CTA, 미입금 강제 취소
- **규칙·로직**: 입금 확인 시 상태 **완료**, 접수 후 **24시간 내 미입금** 시 '미입금' 표시 → 강제 취소(재고 즉시 복원)
- **화면 이동**: 완료 처리/강제 취소 → 예약 관리 목록 상태 반영

### S1-A9 — 취소요청 처리
- **목적**: 고객 **취소요청** 검토 후 환불·취소 확정
- **진입**: 예약 관리(취소요청 탭)의 예약 카드
- **주요 요소**: 결제액·취소 수수료(차등)·환불 예정액·고객 환불계좌, 취소 확정 CTA
- **규칙·로직**: 수수료는 **이용일 기준 차등**, 환불 이체는 **수동**, 이체 후 '취소' 처리 → 재고 즉시 복원
- **화면 이동**: 취소 확정 → 예약 상태 취소

### S1-A10 — 계좌·정책 설정
- **목적**: **입금 계좌**와 **차등 취소 수수료 정책** 설정
- **진입**: 메뉴 → 계좌·정책
- **주요 요소**: 입금 계좌(한국 1건), 이용일 기준 구간별 수수료율, 저장
- **규칙·로직**: 구간·요율 **수치는 관리자 편집**, 여행사 취소 마감 기준일도 여기서 **유연 조정**(기본 D-3)
- **화면 이동**: 저장 → 정책 반영(취소 계산에 적용)

### S2-A1 — 여행사 목록
- **목적**: 여행사 계정 **목록 관리 및 사용 가능/불가** 토글
- **진입**: 메뉴 → 여행사 관리
- **주요 요소**: 여행사 카드(명칭·사용 토글), + 등록 버튼
- **규칙·로직**: 토글 = 사용 가능/불가, **불가 시 로그인·예약 차단**
- **화면 이동**: + 등록 → 여행사 등록(S2-A2), 카드 → 여행사 상세(S2-A3)

### S2-A2 — 여행사 등록(초대)
- **목적**: 여행사 **초대 이메일 발송**으로 계정 등록 유도
- **진입**: 여행사 관리의 + 등록
- **주요 요소**: 여행사명·담당자 이메일 입력, 가입 링크 발송 CTA
- **규칙·로직**: 담당자가 링크로 **아이디·비밀번호 직접 등록**, 링크 **유효기간 1주일**, 이미 계정 있으면 발송 생략
- **화면 이동**: 발송 → 여행사 목록

### S2-A3 — 여행사 상세
- **목적**: 여행사 **상세 정보·담당자 변경·사용 상태** 관리
- **진입**: 여행사 목록(S2-A1)의 카드
- **주요 요소**: 여행사명·담당자·이메일, 사용 가능/불가 토글, 저장
- **규칙·로직**: 담당자 변경은 상세에서, **불가 전환 시 로그인·예약 즉시 차단**
- **화면 이동**: 저장 → 여행사 목록 반영

### S2-A4 — 날짜별 할당 세팅
- **목적**: 여행사별·날짜별 **재고 할당 수량** 세팅
- **진입**: 메뉴 → 할당 세팅
- **주요 요소**: 여행사·상품·날짜 선택, 수량 스테퍼, 저장
- **규칙·로직**: 할당 단위 = **자전거 종류·날짜별 수량**, **총 보유 − 할당 = 고객 가용**(자동), 여행사 예약기간 **+3일 ~ +3개월**
- **화면 이동**: 저장 → 재고 세팅·여행사 예약에 반영

### S2-A5 — 인보이스 목록
- **목적**: 여행사 **월별 인보이스 목록** 조회·발행
- **진입**: 메뉴 → 인보이스
- **주요 요소**: 여행사·월별 인보이스 카드(발행 상태 태그)
- **규칙·로직**: 통화 **KRW**(세금 라인 없음), **매월 1일 전월 기준** 발행, 정산은 **수동 확인**
- **화면 이동**: 카드 → 인보이스 상세(S2-A6)

### S2-A6 — 인보이스 상세
- **목적**: 인보이스 **라인아이템 상세·발행·정산 확인**
- **진입**: 인보이스 목록(S2-A5)의 카드
- **주요 요소**: 예약 건별 라인아이템, 합계(KRW), 발행 CTA, 정산 완료 표시
- **규칙·로직**: 라인아이템 = **예약 건**, 세금 라인 없음, 정산은 **수동 확인**
- **화면 이동**: 발행/정산 표시 → 인보이스 목록 상태 반영

### S4-A1 — FAQ 관리
- **목적**: **FAQ 등록·수정·삭제 및 노출 순서** 관리
- **진입**: 메뉴 → FAQ·콘텐츠

### S4-A3 — 콘텐츠 관리

## 3. 여행사 페이지 (데스크톱)

> 사무실 PC에서 예약·정산. 예약 = **즉시 완료**, 취소 = **즉시**(기본 D-3까지, 유연). 입금 흐름 없음.

### S2-G1 — 계정 등록(초대 링크)
- **목적**: 여행사 담당자의 **계정 등록(초대 링크)**
- **진입**: 관리자 초대 이메일의 링크(토큰 포함)
- **주요 요소**: 아이디·비밀번호·비밀번호 확인 입력, 계정 등록 완료 CTA
- **규칙·로직**: 관리자 초대 이메일 링크로 진입, **링크 유효기간 1주일**, 담당자가 아이디·비번 직접 설정
- **화면 이동**: 등록 완료 → 로그인(S2-G2)

### S2-G2 — 여행사 로그인
- **목적**: 여행사 담당자 **아이디/비밀번호 로그인**
- **진입**: 계정 등록 완료 후, 여행사 로그인 URL
- **주요 요소**: 아이디·비밀번호 입력, 로그인 CTA
- **규칙·로직**: 등록 완료 계정만 로그인, 관리자가 **사용 불가**로 전환 시 로그인 차단
- **화면 이동**: 로그인 성공 → 여행사 대시보드

### S2-G3 — 여행사 대시보드
- **목적**: 신규 예약 현황과 **오늘 이용자 명단** 확인
- **진입**: 로그인 직후, 좌측 사이드바 '대시보드'
- **주요 요소**: 신규 예약 지표 카드, 오늘 이용자 명단 표(예약번호·상품·수량·여권명·상태)
- **규칙·로직**: 여행사 예약은 상태 단순: **예약=즉시 완료 / 취소=즉시**, 입금 흐름 없음
- **화면 이동**: 사이드바 → 상품 예약·예약 목록·인보이스

### S2-G4 — 상품 조회
- **목적**: 할당 범위 내에서 **이용 날짜·상품 조회 및 수량 선택**
- **진입**: 사이드바 '상품 예약'
- **주요 요소**: 이용 날짜, 상품 표(여행사가·가용·수량 스테퍼)
- **규칙·로직**: 가용 = **여행사 할당 수량** 상한(초과 불가), 예약 가능 기간 **오늘 +3일 ~ +3개월**, 여행사가 적용
- **화면 이동**: 수량 선택 → 예약(S2-G5)

### S2-G5 — 예약
- **목적**: 선택 내역 확인 후 **즉시 예약 완료**
- **진입**: 상품 조회(S2-G4)의 예약 요약 보기
- **주요 요소**: 이용 날짜·선택 상품 표, 예약 요약·합계, 예약(즉시 완료) CTA
- **규칙·로직**: 여행사 예약은 **즉시 완료**(입금 흐름 없음), 여행사가 적용
- **화면 이동**: 예약 → 예약 목록/대시보드

### S2-G6 — 여행사 예약 목록

## 4. 핵심 도메인 규칙 요약

**재고·가용성**
- 자산은 총 보유 대수만 관리(사유 미관리), 삭제는 소프트삭제
- 고객 가용 = **총 보유 − 여행사 할당**(Slice 2부터 자동, Slice 1은 직접 세팅)
- 가용성 = 재고 × 슬롯 겹침으로 판정
- 2일 + 타지역 반납 옵션 선택 시 익일·익익일 자동 마감

**예약 가능 기간(일본 기준 '오늘')**
- 고객: 오늘 +1일 ~ +3개월
- 여행사: 오늘 +3일 ~ +3개월

**예약 상태 흐름**
- 고객: 접수 → 완료(입금확인) → 취소요청 → 취소 (24시간 내 미입금 시 관리자 강제취소)
- 여행사: 예약 = 즉시 완료 / 취소 = 즉시 (입금 흐름 없음)

**결제·정산**
- PG 미사용, 무통장 입금 + 관리자 수동 확인, 안내 계좌 1개(한국)
- 취소 수수료: 이용일 기준 차등 요율(관리자 편집), 환불은 관리자 수동 이체
- 여행사 정산: 월별 인보이스(매월 1일 전월 기준), KRW·세금 라인 없음, 수동 확인

**가격 정책**
- 고객가 / 여행사가 이원화, 여행사가는 고객앱 미노출
- 상품별 고객앱·여행사앱 표출 각각 토글

**권한**
- 관리자: 슈퍼어드민(쓰기·설정·처리) / 일반(조회 전용, 접객용)
- 여행사: 관리자 초대(이메일 링크, 유효기간 1주일)로 계정 등록, 사용 불가 전환 시 즉시 차단

**알림**
- 문의 답변 등록 시 카카오 알림톡(알림 인터페이스, 실발송 이연)

**회원**
- 소셜 로그인(카카오/네이버/구글, 확장 가능) + 아이디 설정
- 여권 영문명은 예약 시점에 확보, 회원정보에서 변경 가능
- 회원 탈퇴 시 개인정보 삭제
